# blend

`make test` 跑自检。

低曲线刚度下，姿态切换帧崩塌并传染相邻帧。本模块做隔离与修复：

- **偏移度 E**：切换帧节点相对参考（手工 K 帧）的最大偏移。位置偏移表逐帧记录，超阈值即标为异常帧。
- **隔离间距与偏移度**：物理极限给出单帧最大位移 v_max。把偏移 E 线性分摊到每侧 S 帧吸收，每帧修正量 E/S ≤ v_max，得 **S = ⌈E / v_max⌉**；距切换帧 k 帧的残余偏移 **r(k) = E·max(0, 1−k/S)**。
- **过渡缓冲**：取崩塌区外的原帧作锚点，在 [切换帧−S, 切换帧+S] 内用 smoothstep 重建过渡，再施加跨帧物理极限钳制（单帧位移 ≤ v_max），保证崩塌不再传染。
- **导出对比**：崩塌帧姿态与手工参考帧并排写入 `blend_export.txt`（逐节点 cur/ref/dev），自检同时把每异常帧偏移打印到 stdout。
