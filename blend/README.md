# blend

动画 → 布娃娃的过渡混合，避免切入瞬间瘫倒。`make test` 跑自检。

做法：过渡期间 Verlet 物理链照常积分并解距离约束，输出姿态按骨骼权重在
冻结的动画姿态与实时物理姿态间融合，融合系数走 smoothstep 斜坡，时长由
冲击强度映射（冲击越强时长越短，夹在 `[0.15, 1.20]` 秒）。

自检覆盖：

- 拒绝越界 / NaN 权重，拒绝零、负、NaN 时长与非法冲击
- 首帧不塌：输出仍在动画姿态上
- 末端逐帧与手工调参参考序列比对，位置 / 角度误差给出上界
- 过渡期距离约束始终成立；斜坡单调、无速度反向、末端加速度有界（无抖动）
- 全动画权重锁定姿态、零驱动零抖动两个边界场景
