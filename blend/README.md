# blend

动作切换淡入的双参数优化。`make test` 跑自检。

## 决策变量

| 参数 | 含义 | 范围 |
|---|---|---|
| `T` | 淡入时长（秒） | `[tmin, tmax]` |
| `alpha` | 幂函数缓动 `w(u) = u^alpha`（u=t/T）的指数 | `[amin, amax]`，必须为正 |

`alpha = 1` 线性，`> 1` 缓入（抑制切换瞬间的起步冲击），`< 1` 缓出。
`w` 严格单调且端点固定（`w(0)=0, w(1)=1`），因此混合速度在淡入起点等于旧动作、终点等于新动作。

## 混合与核验

末端速度混合：`v(t) = (1-w(u))·vA(t) + w(u)·vB(t)`，速度曲线按分段常数片段给定。

- **末端位移误差**（积分核验）：`e = |∫₀^T (vB − v) dt|`，即新动作参考位移与实际混合位移之差。
  积分用 128 段辛普森公式；自检另用 512 段梯形公式独立复核，两法偏差上界 `QUAD_BOUND = 1e-4 m`。
  恒速情形还有解析解 `e = |Δv|·T·α/(α+1)` 对照。
- **峰值加速度**：对混合速度做节点中心差分，取模长最大值。
- **起步加速度** `start_acc`（可选约束 `start_acc_max`，0 表示关闭）：对切换瞬间做前向差分，
  刻画"起步冲击"。这是唯一会把最优解推入 `alpha > 1` 区域的约束——自检用
  `easing_driven_by_constraint` 验证：关闭该约束后最优 α 回落到 ≈1。

## 约束与代价

约束：盒约束 + `e ≤ emax` + `acc_peak ≤ acc_max` +（启用时）`start_acc ≤ start_acc_max`。

归一化加权代价（三项都除以上界，权重非负且和为正）：

```
J = (w_dur·T/tmax + w_err·e/emax + w_acc·acc_peak/acc_max) / (w_dur+w_err+w_acc)
```

## 求解器

固定 T 时，可行性对 α 不是简单区间：α 太小违反起步/峰值加速度，α 太大违反误差预算，
而峰值加速度本身对 α 非单调，可行集可能是若干离散小区间。因此先做 24 点 α 粗扫描定位
可行段，再对每段边界二分夹取。

| 求解器 | 构成 | 用途 |
|---|---|---|
| `solve_exhaustive` | 80×80 密集网格 + 脊线精修（T 上三分收缩，每探针复用 α 括号局部二分） | 基准解 |
| `solve_fast` | 6×6 粗网格选种 + 多起点坐标模式搜索（含对角移动与重启动）；仅当 `start_acc_max > 0` 时追加 6 点扫描的脊线精修 | 在线解 |

无导数模式搜索在窄而弯曲的可行 sliver 上会结构性停滞，脊线精修是两个求解器共用的
正确性保障，不是快速解的近似补丁。

## 自检声明的上界

每个可行案例都同时跑两个求解器并核验：

- 代价偏差 `|J_fast − J_exh| ≤ COST_BOUND (5e-3)`（归一化代价单位）
- 末端位移误差偏差 `|e_fast − e_exh| ≤ ERR_BOUND (2e-3 m)`
- 快速解评估次数少于穷举的 1/4
- 快速解自身严格满足全部约束（含容差 1e-6/1e-7）

覆盖案例：快动作（大速度差、紧误差预算）、慢动作（严格加速度限制、内点解）、
防冲击（起步约束激活，最优 α≈1.22）、分段时变速度、写死默认值失效对照。

## 无解与非法输入

约束无可行解时两个求解器都返回 `SOLVE_INFEASIBLE`，输出参数为哨兵值
（`T = alpha = -1`），同时给出 `min_violation`——扫描中最小的最大归一化违约量
（误差/峰值加速度/起步加速度各自超界百分比的最大值），供调用方决定放宽哪个约束。
**不会退回任何默认参数。** 问题描述本身非法（上下界倒置、`alpha ≤ 0`、预算非正、
权重全零等）返回 `SOLVE_BAD_INPUT`。
