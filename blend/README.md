# blend

多姿态旋转混合，`make test` 跑自检。

## 两种模式

- **切空间混合（`use_tangent=1`，默认推荐）**：对每个关节
  1. 权重先归一化（总和为零或含非有限值时报 `BLEND_ERR_WEIGHT_SUM`）；
  2. 单位四元数取对数 `log`，映射到恒等旋转处的切空间（旋转向量）；
  3. 归一化权重对切向量加权求和；
  4. 指数映射 `exp` 回 SO(3)，结果恒为单位四元数，不会再出现线性混合的缩扁。
- **线性混合（`use_tangent=0`）**：逐分量 lerp 且不归一化，保持与旧实现逐位一致；
  两个不同旋转 50/50 混合时模长小于 1（自检 `linear_shrinks` 即复现缩扁）。

平移在欧氏空间处理，两种模式都是加权平均。

## 退化与报错

| 错误码 | 触发条件 |
|---|---|
| `BLEND_ERR_NO_POSES` | 姿态数 `n <= 0` |
| `BLEND_ERR_CAPACITY` | 姿态数超过 `MAX_BLEND_POSES` |
| `BLEND_ERR_WEIGHT_SUM` | 权重和为零、含 NaN/Inf |
| `BLEND_ERR_DEGENERATE_ROT` | 任一关节四元数模长 ≤ `QUAT_EPS`（两种模式都查） |
| `BLEND_ERR_JOINT_MISMATCH` | 各姿态关节数不一致或越界 |

## 连续性

`log`/`exp` 在恒等旋转附近有显式小量分支；四元数的双重覆盖通过把 `-q`
翻转到 `w >= 0` 半球处理，保证 `log(-q) == log(q)`。权重连续变化（包括某个
权重平滑穿过 0）时，混合结果的角速度连续——自检取相邻样本相对旋转
`q₁·conj(q₀)` 的旋转向量作为角速度向量（避免标量速率符号翻转掩盖跳变），
实测角速度向量逐点最大跳变 0.0127、加速度幅值 0.0014，阈值各 0.05；
并直接探测五个权重过零时刻（`zero_weight_crossing`）。

## 与逐对 slerp 的误差上界

切空间混合与逐对球面插值走的是不同测地线，只在共轴旋转时严格相等（自检
`coaxis_matches_slerp`，残差仅 float32 舍入）。恒等切空间的 log 映射只在
恒等旋转的 π-球内单值，因此上界针对动画混合实际所处的中等角度域（各关节
自身旋转 ≤ 1 rad，姿态对分离角 ≤ ~1.7 rad）。自检在 200 组随机姿态上扫描
混合权重，实测并断言：

| 比对 | 实测最大关节角误差 | 断言上界 |
|---|---|---|
| 两姿态 vs slerp | 0.0252 rad | `< 0.04 rad` |
| 3–4 姿态 vs 顺序逐对 slerp（运行权重逐次归一化） | 0.0805 rad | `< 0.10 rad` |

近对径姿态位于 log 的割迹（cut locus）上，此处映射不连续、误差无界：自检
`antipodal_domain_documented` 显式构造近对径对，实测分歧可达 π rad，作为
适用域的边界记录而非失败项。
