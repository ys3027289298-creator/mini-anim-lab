# blend

动画/物理混合的连续性分析，`make test` 跑自检。

混合姿态 `p(t) = (1-w(t))·anim(t) + w(t)·phys(t)`，求导得

```
p'(t) = (1-w)·anim' + w·phys' + w'·(phys-anim)
```

所以速度断点只可能来自 `w'` 的跳变、两端输入的采样速度跳变，或 `w` 自身的跳变。

- 权重曲线按 knot 显式给出：`linear` / `smooth` / `hold`。knot 的求导一侧值、导数跳变量与解析上界都能取到。
- `blend_breaks` 列出所有内部断点，带左右导数 `dw_lo` / `dw_hi`、精确跳变 `jump` 与三角不等式上界 `bound`。
- `blend_intervals` 给出 `p'` 存在且连续的区间（断点补集），以及区间内 `w ∈ [0,1]` 的判定。
- `blend_compare` 用中心差分速度与闭式导数逐点比对；断点附近的采样因差分模板会跨越跳变而被跳过。
- `blend_step_check` 在单侧探针上测数值速度跳变，验证它落在 `[jump, bound]` 内。
- `blend_gate` 在单帧处把关：权重不可导、holder 跳变、权重越界、求值域外、方向夹角超阈值都会报告（`ok = 0`），而不是静默混合。
- `hold` 结束处的 `w` 跳变让速度无界（脉冲），报告为 `INFINITY`，姿态跳变另给 `pose_jump = |Δw|·|d|`。

边界 knot（`t = 0` / `t = T`）不算断点，混合在域外被 clamp。

自检覆盖：闭式导数与数值微分一致、线性拐角的速度跳变与上界、smoothstep 相接的 C1 区间、hold 的无界速度与姿态跳变、纯输入速度断点、权重与输入跳变部分抵消时上界严格大于跳变、方向夹角绕回、权重越界、容量与非法 knot。
