# collision

Verlet 粒子链对圆形障碍的连续碰撞检测（CCD），解决高速摆动时“穿过去再弹回来”的穿透问题。

`make test` 跑自检。

## 做法

- `seg_circle_hit`：只取**入射命中**，按上一帧位置 → 当前位置的扫掠线段与圆求交，
  线段起点在圆内时不报命中（交给深度穿透回退分支）。
- 命中后回推到首次接触时刻、离命中点最近的表面位置，Verlet 锚点 `(px,py)` 同步平移，
  重建出的速度只保留切向分量。
- 单步残余穿透由 `pen_cap` 给上界；`worst_raw_pen` 记录修正前深度，`cap_clamps`
  记录触发夹紧的次数。
- 零恢复系数：接触粒子的法向速度只夹到零、不取反，`reversed` 统计反向跳变（自检要求恒为 0）。
- `rope_step` 对 `dt <= 0` 返回 `-1` 报错。
- `rope_step_naive` 是只投影当前位置的朴素求解器，自检用它复现穿透，再与 CCD 结果对照；
  粗步长 CCD 还会与 64 细分步长的高精度结果比对。
