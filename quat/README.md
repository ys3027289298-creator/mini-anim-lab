# quat

四元数最短三元素压缩：丢掉模长最大的分量，存其余三个，解码时按
`+sqrt(1 - x² - y² - z²)` 恢复并重归一。`make test` 跑自检，同时打印
压缩率与误差的关系表。

## 编码

1. 归一化，找 |q_i| 最大的分量 `drop`。
2. 若该分量为负，整体取反（`q` 与 `-q` 是同一旋转），保证解码可用正根。
3. 按槽位顺序存其余三个分量，外加 2 bit 的 `drop` 索引。

## 误差上界

三个保留分量落在 `[-1/√2, 1/√2]`，用 b bit 有符号定点表示，单分量误差
`h = 2^-b / √2`。记保留三元组为 k、丢弃分量为 d（因 d 最大，`d ≥ 1/2`，
`|k|² = 1 - d² ≤ 3/4`），量化后 `k' = k + e`，`|e| ≤ √3·h`。解码输出
`p = (k', s)/|(k', s)|`，`s = √(1 - |k'|²)`。由此：

```
|p - q| ≤ √3·h + δ,
δ = (3h + 3h²) / ( (1/4 - 3h - 3h²)·(1 + 1/√(1/4 - 3h - 3h²)) )
角度误差 ≤ 4·asin(|p - q| / 2)
```

与数据无关，只依赖 b。实测（随机 + 对抗扫描）约为上界的 0.6 倍，界本身
在 `quat_angle_error_bound()` 中实现并由自检断言。`b < 4` 时根号内可能
非正，只剩平凡的 π 界。

## 压缩率 / 误差

位宽 = 3b + 2（三个分量 + 2 bit 索引），对照 3×3 旋转矩阵 9×32 = 288 bit
与四元数 4×32 = 128 bit：

| b | 总位数 | 相对矩阵 | 相对四元数 | 最坏角度误差 |
|---|---|---|---|---|
| 6  | 20 | 0.069 | 0.156 | 7.83° |
| 8  | 26 | 0.090 | 0.203 | 1.85° |
| 10 | 32 | 0.111 | 0.250 | 0.456° |
| 12 | 38 | 0.132 | 0.297 | 0.113° |
| 14 | 44 | 0.153 | 0.344 | 0.0284° |
| 16 | 50 | 0.174 | 0.391 | 0.0071° |

实际写入一般用 16 bit 半精度（每分量）或 10–12 bit 定点；相对整矩阵可省
83–95% 的空间。`make test` 会逐个 b 用随机数据加 `±h` 对抗扰动实测，
断言不超过解析上界。

## 失败情形

- 输入模长 `< 1e-6`（含 NaN）：`q_compress` 返回 -1，无法可靠恢复被丢的
  分量。更小但仍有限的正模长会先归一化再编码。
- 载荷自相矛盾（保留分量平方和 > 1，恢复出虚数）或 `drop` 越界：
  `q_decompress` 返回 -1。
