# coupling

绳索（Verlet 粒子链，见 `../constraint/`）与两骨手臂（解析 IK，见
`../ik/`、`../skeleton/`）的双向耦合。

## 求解流程

每帧按下列顺序交替迭代，直到残差低于容差或用尽迭代预算：

1. 绳索距离约束（PBD，按逆质量加权，同 `constraint/`）；
2. 耦合约束：锚点/附着点的错位按逆质量比分配修正量
   `frac_rope = w_rope/(w_rope+w_hand)`、`frac_hand = w_hand/(...)`，
   手部修正量经解析 IK 回写，实现手臂拉绳、绳也拉手的双向影响；
   IK 到达可达边界被夹取时，手做不到的份额回退给可动锚点；
3. 手臂胶囊碰撞（最后执行），把锚点之外的绳粒子投影到接触面上，
   保证帧末零深穿透。锚点由耦合约束拥有、放在骨骼附着点的安全
   偏移处，碰撞不移动它以免重新注入耦合误差。

挂点是手部局部系下的固定偏移，随骨骼变换自动跟随。

## 关键指标与报告

- **残差** = max(绳索段拉伸误差, 锚点-附着点错位)，每轮记录历史；
  超过迭代预算仍高于容差则置位 `non_converged`，并保证该标志与
  最终残差严格一致（扫描测试验证无虚报、无漏报）。
- **零穿模**：接触 slop 允许静止粒子有不超过 `collision_slop` 的浅
  重叠（给距离约束留可行域），超出 slop 面即计为深穿透，计数必须为
  零；浅重叠量通过 `max_visual_overlap` 透明上报且有界。
- **质量比**：两侧逆质量均为 0（比例无定义）返回错误；单侧为 0 报告
  one-sided；锚点钉死且 IK 夹取的真冲突无法消解，按不收敛报告。
- **IK 夹取**：目标超出可达范围被夹到可达环带并置位 `ik_clamped`。

## 自检

`make test` 跑自检，覆盖：质量比分配、收敛/不收敛报告、IK 夹取上报与
吸收、与手工硬钉挂点基线的穿模对比（基线 191 次穿模、耦合方案 0 次）、
双向拉扯、单侧质量、真冲突、以及 36 组参数 / 4320 帧的稳健性扫描。
