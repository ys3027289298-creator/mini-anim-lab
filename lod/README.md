# lod

距离约束链的约束 LOD。

- `stride` 决定保留哪部分粒子为活动节点（其余按静止长度插值重建），
  `iterations` 同时作为档位参数，所以减配同时减约束数和迭代数。
- 档位由相机距离与屏幕占比联合选择，带滞回，边界上不会逐帧抖动。
- `stride = 0` 是 cull 档：所有粒子照常积分但零约束，链条自由落体。
  该档在自检中显式报告为 **culled / unbounded**，不会伪装成正常求解。
- 切换连续：`lod_switch()` 不动任何粒子状态；切换后每帧的约束修正被限速
  到 `ENGAGE_RATE*dt`，逐步啮合，因此任何单帧的切换位移都有硬上界。
- 自检按距离档位输出：实测姿态误差（对照全量解）、该档声明的误差上界，
  以及上界折算到该距离处视口像素数；另输出每帧步偏差与切换连续性数字。

`make test` 跑自检。
