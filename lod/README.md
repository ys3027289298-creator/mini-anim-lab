# lod

骨骼 LOD 切换。两套骨架（near 6×0.6，far 3×1.2）播放同一段动作，
far 的关键帧晚 0.35 s、摆幅略小；直接换骨架时远端关节会跳。

- 切换区间是距离带 [3.6, 5.4]。进入带内即按进入方向挂起切换，
  由代价阈值决定在哪一帧真正交接：代价 = 对齐后关键点残差 / 两套
  骨架自身每帧步长。动作越忙代价越高，阈值因此会等到安静的一帧。
  若离开带前始终没有便宜帧，则在带边缘强制切换并标记。
- 过渡段 = 0.2 s，从触发帧起沿进入方向展开；进入方的匹配关键点
  （near 关节 2/4/6，far 关节 1/2/3）在触发帧做相位对齐并提交。
- 两套骨架分别记录：接入/离开帧与时间、交接残差、窗口内最大显示步长。

`make test` 跑自检，并会把整个报告跑两遍逐字节比对（`repro_binary`）。
时序只是帧号的函数（frame × dt），无累积时钟、无随机，重复运行
触发帧完全一致，测得偏差 0 帧，远小于半帧上限。

| 量 | 值 |
|---|---|
| 触发帧（near→far / far→near） | 121 / 290 |
| 触发时刻 | 2.016667 s / 4.833333 s |
| 交接残差（far / near 吸收） | 0.234 / 0.167 |
| 切换帧显示步长 | 0.360 / 0.075 |
| 未过渡硬切的跳变 | 3.693 |

## 结果速览

`./lod` 打印每个场景的完整记录；`make test` 额外做两遍运行的逐字节比对。
`fixed` 是修复后，`cross` 是旧的距离穿越即切换（复现跳动），
`ungated` 是带内无阈值门控，`noalign` 是不做关键点对齐，
`forced` 是阈值不可达时由安全阀在带边缘接管。
