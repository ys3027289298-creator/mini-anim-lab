# stitch

两段三次 Hermite 动画曲线在接缝处做 **C2 拼接**。`make test` 跑自检。

## 思路

- 接缝两侧各取一段三次 Hermite，转 Bézier 表示。外侧控制点（端点值、外侧
  切线）保持原动画不动，内侧两个控制点 `x`（左）、`y`（右）为未知量。
- C0：接缝公共点 `J` 取两 clip 接缝值的平均。
- C1（接缝两侧控制点与 J 共线、切线相等）与 C2（Bézier 末端二阶导相等）
  构成关于 `x, y` 的 2×2 线性方程组：

```
C1: [  dR      dL   ] [x]   [ J(dR+dL)                          ]
C2: [ -2dR²    2dL² ] [y] = [ dL²P4 − dR²P1 + J(dL²−dR²)         ]
```

- 另构造归一化系统（`x̂=x/dL, ŷ=y/dR, s=dL/dR`），其 ∞-范数条件数无量纲、
  在两侧区间长度相当时为 O(1)；条件数超阈值或行列式退化时拒绝并返回原因，
  不硬拼。实际控制点仍由物理单位系统解出，两套系统分开，避免量纲混用。
- 解出的 Bézier 控制点反算回 Hermite 的四个量（含内外两侧切线）。
- 手工拼接基线只把两侧端点拉到同一位置、各自保留原切线（C1 都可能不满足），
  其接缝二阶导跳变保留为对照。

## 拒绝路径

| 状态 | 原因 |
|---|---|
| `STITCH_BAD_INPUT` | 非有限输入、窗口退化、采样点不足、接缝不在 clip 域内 |
| `STITCH_NO_OVERLAP` | 两段时间域无重叠 |
| `STITCH_WINDOW_OUT_OF_RANGE` | 评估窗两侧不能分别被 A/B 覆盖，或未跨过接缝 |
| `STITCH_SINGULAR` | 接缝邻接区间长度为零 / 归一化行列式低于容差 |
| `STITCH_ILL_CONDITIONED` | 条件数超过 `COND_MAX`（1e6），控制点数值不可靠 |
| `STITCH_NONFINITE_SOLUTION` | 解出的控制点非有限值 |

## 二阶导跳变上界

Bézier 在接缝的两个二阶导为

```
d2L = 6 (J − 2x + P1) / dL²        d2R = 6 (P4 − 2y + J) / dR²
```

C2 行强制 `dR²(J−2x+P1) = dL²(P4−2y+J)`。记物理残差
`ρ = |dR²(J−2x+P1) − dL²(P4−2y+J)|`，则严格上界为

```
|d2L − d2R| ≤ 6ρ / (dL²dR²) + 8·eps·(|d2L|+|d2R|)
```

第二项是 float32 求值的舍入余量。自检同时验证：测量跳变不超过该上界，且
远小于手工拼接基线的跳变（标称用例 0 对 12）。
