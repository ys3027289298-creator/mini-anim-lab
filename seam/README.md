# seam

三段剪辑（stand → crouch → jump）根骨骼高度曲线的接缝对齐与脚底接触验证。

- 每段剪辑自带一条根骨骼高度曲线（三次埃尔米特，零切线），曲线间存在常量垂直偏移，导致接缝处脚短暂离地。
- `align_seams`：逐段平移曲线，使每段起点与上一段终点高度一致（C0）。
- 脚底高度模型：腿长（髋到脚最大伸展）`LEG_REACH = 1.0m`，根骨高度超过腿长时脚底离地，距离为 `root - LEG_REACH`。
- 波动压缩：接地帧上根骨高度夹取到 `LEG_REACH`（foot-plant），腾空帧（jump 起跳后）不动；压缩后整段接地帧脚底高度波动 ≤ `FLOAT_THRESHOLD = 0.01m`。
- 输出接缝前后各十帧的脚底离地距离（修复前/修复后），三段各一份。
- 单段测试：打开接缝，每段单独在自己的曲线上测接地帧离地，区分"段内固有离地"与"接缝离地"。

`make test` 构建并运行自测。
