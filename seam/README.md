# seam

循环动画接缝修正。`make test` 跑自检。

一条姿态通道采样为 `p[0..n-1]`（`p[n-1]` 回卷到 `p[0]`）。`seam_fix`
按周期性约束建立首末帧等式——接缝处 0..3 阶 jet 相等（单边差商，逐点，
对次数 ≤ m+2 的多项式精确），在光滑 Hermite 基（单调 C3 smootherstep
承载值跳变，`u^k(1-u)^4` 承载 k 阶导数失配，窗缘处 jet 全零）张成的
子空间内求弯曲能量最小的修正，即最小姿态偏移意义下的最小二乘解，
闭式 `c = R⁻¹Bᵀ(BR⁻¹Bᵀ)⁻¹b`。修正后接缝三阶连续，修正曲线本身单调
无振铃（原始欧氏范数最小解必然集中在接缝样本上形成尖刺，故目标取
弯曲能而非 `‖d‖`）。

`SeamReport` 给出认证上界：

- `residual[0..3]` / `residual_bound[0..3]`：各阶接缝残差实测值与
  先验舍入上界；
- `offset_max`：实测最大修正量（即所需带宽）；
- `offset_bound`：修正范数的先验上界，
  `‖d‖₂ ≤ ‖Φ‖₂·‖T‖₂·‖M⁻¹‖₂·‖b‖₂`（用 `‖X‖₂ ≤ √(‖X‖₁‖X‖∞)`）。

所需修正量超过 `bandwidth` 时返回 `SEAM_ERR_BANDWIDTH`，明确报不可
修正，原数据一个字节不动，绝不硬压。多通道姿态逐通道调用。

自检内容：差商权重与最小范数求解器同解析解对拍（rank-1 / 加权 /
2×3 KKT）、已周期片段近零修正、斜坡跳变（接缝跳 1.0）全认证修复
（残差≤界、偏移≤界、内部样本不动、局部多项式拟合残差 0.35→8e-4、
修正单调无过冲）、带宽拒绝且数据不变、已知可行修正的最优性证书
（解的弯曲能 ≤ 已知可行修正的弯曲能）、参数校验。
