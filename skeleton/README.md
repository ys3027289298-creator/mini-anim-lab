# skeleton

骨骼层级、世界变换与骨段扫掠包围体。`make test` 跑自检。

## 包围体流程

1. 每根骨按胶囊体处理：单位骨段沿法线扫掠半径 `radius[i]`。
2. 用端点两个外接正多边形近似胶囊（胶囊恰为两端圆盘的凸包），
   多边形比真实胶囊略大，保证圆帽不被削掉。
3. 按层级自底向上逐层合并：子骨凸包并入父骨凸包并重新求凸包，
   最后把各根骨的凸包合成整体凸包。
4. 在凸包各边方向上求最小面积包围盒（旋转卡壳性质：最优盒必有一边
   与某条凸包边共线）。
5. 校验：对每根骨密集采样真实胶囊表面，
   - 落在包围盒外的顶点数必须为 0；
   - 相对逐顶点紧包围盒（AABB）的面积冗余不超过
     `1/cos²(π/N) - 1`，N=32 时约 0.97%。

`bone_bounds()` 另外返回每根骨自己的最优包围盒和逐顶点 AABB，
方便逐骨剔除时使用。

## 约束与报错

| 情况 | 行为 |
|---|---|
| 半径为负 / NaN / Inf | 拒绝添加或设置，`skel_error() == SKEL_ERR_RADIUS` |
| 父子关系成环（含自环、间接环） | 拒绝 `skel_set_parent`，`skel_error() == SKEL_ERR_CYCLE` |
| 父索引越界 | `SKEL_ERR_PARENT` |
| 索引越界 | `SKEL_ERR_INDEX` |
| 容量超限 | `SKEL_ERR_CAPACITY` |

`skel_update()` / `skel_hull_layered()` / `bone_bounds()` 会先做完整结构校验
（含环检测），非法层级直接返回错误码，不产生负权限或死循环。
父索引必须先于子索引，以保证单次顺序遍历即可求世界变换。
