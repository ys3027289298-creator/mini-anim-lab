# camera

镜头运动模块：把镜头线加速度与角速度联合评价为单一应力（stress），
据此在运动终点施加制动阻尼；模拟三档灵敏度摄像机在剧烈运镜下的
帧截图并叠加对比锐度；拍摄急停后的微弹回，测量稳定时长，并比较
自动阻尼与用户手动抵消两种模式。

## 构建 / 测试

```
make test
```

运行自测，并在 `out/` 生成：

| 文件 | 内容 |
|---|---|
| `frame_low/mid/high.pgm` | 三档灵敏度各自最糊一帧的截图 |
| `sharpness_compare.pgm` | 三帧 + 各自边缘图 + 三帧叠加混合的对比图 |
| `bounce_capture.pgm` | 急停后弹回峰值帧（上） vs 稳定帧（下） |
| `bounce_trace.pgm` | 弹回位移曲线，亮线=自动阻尼，灰线=手动 |

## 判定

- 锐度随灵敏度升高而下降（运动模糊更宽）。
- 弹回需出现至少两次过零（确有"弹回"而非单调衰减）。
- 两种模式的稳定时长差 **短于半帧（1/120 s）即判失败**。
