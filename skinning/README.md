# skinning

线性混合蒙皮（LBS）与对偶四元数蒙皮（DQS）对照，`make test` 跑自检。

## DQS 流程

1. 每根骨的刚体世界变换（R, t）合成对偶四元数：实部 `r = R`，
   对偶部 `d = 0.5·t_q·r`；
2. 皮肤变换取 `S = W·B⁻¹`（先在绑定姿势求逆，矩阵用刚体逆，对偶四元数用
   `(Rᵀ, -Rᵀt)`）；
3. 按权重线性混合各骨的皮肤对偶四元数（先做 antipodality 半球对齐），
   再整体归一化；
4. 位置 `p' = r·p·r* + 2(d·r*).xyz`；法线只乘旋转部 r，平移不参与；
5. 两种错误入口都返回错误码而非静默继续：
   - `DQ_ERR_ZERO_DUAL`：对偶部为零（无平移的退化对偶四元数）；
   - `DQ_ERR_ZERO_WEIGHT`：某顶点权重和不大于零。

   因此测试姿势都带一个根骨小旋转，使每根骨的皮肤变换都含非零平移；
   绑定姿势的恒等皮肤变换（对偶部为零）会被零对偶守卫正确拒绝，
   其恒等性单独用解析断言校验。

LBS 路径混合 4×4 皮肤矩阵；位置用混合矩阵，法线走逆转置方向。逆转置用
余子式矩阵 `cof(A) = det(A)·A⁻ᵀ` 实现，归一化后等价且不会在奇异混合处
除以零行列式。

## 测试网格与指标

管状体网格包在 3 骨链外（104 顶点、192 三角形，绕序朝外），顶点最多挂
两根骨，末骨覆盖的环全部满权重。每个关节拥有跨两侧各一个骨段的板片
（3 个环、含端盖的封闭曲面）。逐关节、逐姿势报两个数：

- **vol**：板片封闭网格体积相对绑定姿势的相对误差（带符号四面体求和，
  端盖按几何法线自动取一致绕序）；
- **nrm**：蒙皮输出法线与“从变形后位置重算的面法线（邻接面面积加权）”
  的平均夹角（度），即输出法线是否贴合它实际产生的表面。

两种蒙皮跑同一网格、同一批 8 个极端姿势（120°–180° 弯曲/扭转、折叠、
反向对拧），并校验：

- 同一姿势下两者顶点数一致，且都等于网格顶点数；
- 纯刚体姿势（仅根骨旋转）下两法板片体积严格不变，验证体积测量本身；
- 单骨满权重顶点是刚体运动，LBS 与 DQS 位置、法线必须重合；
- 绑定逆的矩阵/对偶四元数往返为恒等，绑定皮肤变换解析为恒等。
