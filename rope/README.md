# rope

单侧（只拉不推）距离约束的 Verlet 绳链，在 `constraint/` 基础上加张力估计与断裂。

`make test` 跑自检。

## 张力反推

PBD 单次迭代中粒子 b 的修正量等价于冲量位移 `w_b·T·dt²`，故单次迭代
`T = stretch / (w_sum·dt²)`；对全部迭代求和得到该步张力。松弛段
（`stretch ≤ 0`）不产生修正，张力恒为零——绳子不能推。

## 断裂

- 步末取 `T / T_max` 最大且超过 1 的段断开，每步最多一段（确定性级联）。
- 断开只翻 `broken` 标志、不修改任何坐标，因此断裂前后端点位置严格连续；
  自检验证断裂步与一条永不断裂的参照绳逐粒子位姿完全相同。
- 断裂段约束永久跳过，脱离子链降级为自由端（质心严格满足自由 Verlet 运动，
  内部约束力成对抵消）。
- `rope_set_limit` 拒绝零、负和 NaN 上限，返回 -1 且保留原值。

## 与解析静力比对及误差上界

竖直悬挂、单位质量的链，段 i 的静力张力为 `(n-1-i)·g`。对每个自由粒子 j
定义力残差 `r_j = T_{j-1} − T_j − mg`，望远镜求和得

```
T_est_i − T_static_i = Σ_{j>i} r_j,   |误差| ≤ Σ|r_j|
```

右式即代码实际计算并断言的严格误差上界（自检输出 `threshold_bound` 与
实测 `measured_max_err`）。
