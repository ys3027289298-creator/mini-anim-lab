# contact

绳-绳接触，接在 `constraint/` 的 Verlet 粒子链之上。`make test` 跑自检。

## 流程

1. **粗筛** `contact_broad`：按段对做 AABB 重叠测试，盒体按两根绳的半径和
   外扩，只保留可能接触的段对。
2. **窄相** `contact_narrow` / `signed_refresh`：对每个候选段对求精确最近点
   （`seg_seg_closest`，覆盖相交、共线重叠、端点最近等构型，内部用内部驻点加
   四个边界候选保证不遗漏），穿透量 `depth = rA + rB - dist`，`depth > 0` 才
   生成接触。
3. **求解** `contact_project`：每个接触作为位置级 PBD 约束加入 Verlet 迭代，
   接触点用重心坐标映射回四个端点、逆质量加权投影；固定粒子（`inv_mass=0`）
   不动。距离（拉伸）约束与接触约束在同一个迭代循环内交替，每轮先拉伸后接触，
   接触投影是每轮最后一步，否则下一轮拉伸会把分离顶回去。

### 交叉（零距离）法线

普通接触有几何法线（两最近点连线）。但两根绳中心线相交时最近点距离为 0，
没有几何法线。此时不存在一条对两根绳都正确的公共法线——每根绳应沿**自身
切线的垂直方向**弯开（水平绳上下弯、竖直绳左右弯）。`pair_axes` 用绳级
（首尾粒子，而非当前段）方向求两个稳定的单位垂直方向 `nA/nB`，符号由 A 首
粒子相对 B 支撑直线的侧别决定。用绳级几何保证最近点在相邻段对之间跳变时
方向不翻转，这是早期版本出现横向振荡的根因。接触按 `(绳对, 段对)` 在
`signed_update` 里保持持久槽位，几何每轮刷新、身份不变。

### 退化与报错

- 共线重叠等极端情形：法线逐级回退到 A 段垂直、B 段垂直、y 轴，自检保证
  恒为单位向量。
- **零长度段报错**：`rope_init` 拒绝并返回 -1；`rope_validate` / `scene_step`
  在积分前检查，返回 -1 且不改动任何粒子状态。

## 细分参考验证 `contact_fine`

把每对段细分成 `sub×sub` 个子段重算穿透，作为参考：

- `missed == 0`：粗筛丢弃的段对中不存在任何参考接触（漏检为零）；
- 子段中点相对父段的偏差不超过半个子段长，因此粗相穿透量不超过细分穿透量加
  `margin = 0.5·(最长A段 + 最长B段)/sub`，即粗相最大穿透被该和上界夹住；
- 细分越密 `margin` 越小，自检里对这两条都有断言。

## 迭代预算分配 `contact_budget`

拉伸约束始终保留全部迭代。只要存在接触，最后 `iterations-1` 次迭代都在拉伸后
跟一次接触扫描，使两类约束交替收敛；`cap` 限制**每次**扫描处理的接触数，按
穿透深度从大到小优先解最深的。当接触数超过单批容量时，扫描数延长到
`ceil(n/cap)`，但至少保留一次纯拉伸迭代。因此每帧接触工作量上界为
`k·cap`，接触数激增时总代价有界；`contact_cap <= 0` 时接触整体关闭
（对照组：两根绳直接互相穿过，残差恒为初始穿透量）。

## 自检场景

- 段对最近点：平行、交叉、端点、共线；
- 交叉绳接触检测、平行绳法线方向、细分参考的漏检与上界；
- 单端固定交叉绳：接触被推开、主导分离方向正确、钉点不动；
- 重力下悬垂绳穿过两端固定绳：300 步有限且不穿透（无隧穿）；
- 锯齿绳与直绳大面积相交（数十接触）：预算上限被遵守；
- 零长度段在初始化和步进两处都报错。
