# mini-anim-lab

角色动画基础模块，C 实现，每目录独立构建可自测。

| 目录 | 内容 |
|---|---|
| `skeleton/` | 骨骼层级、世界变换、骨段求取 |
| `ik/` | 双骨解析 IK、极向量、可达性判定 |
| `constraint/` | 距离约束链条、Verlet 积分、迭代收敛 |
| `path/` | 折线弧长表、按距离采样、曲率与最近点 |
| `curve/` | 关键帧采样、三次埃尔米特切线、夹取 |
| `hysteresis/` | 分段刚度滞回本构、加载/卸载双曲线、环面积可配、手工测试比对与回弹误差上界 |
