# knockback

冲量驱动的击退：攻击强度即冲量 J，命中只改变速度不挪位置，位移由速度积分得到。

`make test` 跑自检并打印三种质量比（固定 J=10，m=1/2/4 → J/m = 10/5/2.5）下的
初速度、峰值位移、回静止时间，以及阻尼系数与时间的并列对照。

- 正确模型：`F = -m·k·v`，`dv/dt = -k·v`，衰减率 k 与质量无关；
  峰值位移 = 积分 `∫v dt = v0/k = J/(m·k)`，越重滑得越近。
- 错误模型（自检内置）：`F = -c·v`，`dv/dt = -(c/m)·v`，
  阻尼被质量比反向缩放——最大 J/m 组反而最先静止，峰值位移 J/c 与质量无关。
- 静止判据：`|v| < 0.05` 后夹零；积分用半隐式欧拉，`dt = 1/60`。
