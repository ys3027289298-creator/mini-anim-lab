## 误差带拟合（curve_fit）

把稠密采样（几百个关键帧）压缩成少量三次埃尔米特段：

- **分段**：在参数空间贪心延伸，段内采样点的 L∞ 偏差超过 `band` 即切断；
  段内为三次埃尔米特（端点精确插值、切线由采样差分估计），段界共享切线，整体 C1。
- **逐点校验**：拟合完成后在每个原始采样点复核，最大偏差写入 `FitInfo.max_dev`，
  保证不超过 `band`。
- **拒绝**（返回 -1，输出曲线不变）：`band <= 0`、采样少于 2 个、时间非严格递增、
  或所需段数超过 `max_segments`（上限 `MAX_KEYS - 1`）。
- **分段数与带宽**：带宽越大段数越少（单调不增）；三次段的局部误差 ~ h⁴，
  故段数大致按 `band^(-1/4)` 缩放。`make test` 的 sweep 输出给出实测关系，
  带宽过紧导致超段数上限时整体拒绝而非截断。
- 不调用 `curve_fit` 时行为与之前完全一致（拟合是可选项，原有 API 未动）。
