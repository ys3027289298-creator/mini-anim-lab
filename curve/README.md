# curve

关键帧采样（三次埃尔米特切线、越界夹取），以及周期循环曲线的 C2 周期延拓。

`make test` 跑自检。

## 周期 C2 延拓（`periodic_init` / `pc_eval`）

循环动画的关键帧只描述一个周期 `[t0, t0+period)`。朴素的“整段重建 + 末段三次
外推”在首尾会突然加速：末段三次多项式被继续拉长，高次模按距离指数放大，接缝处
二阶导还会跳变。

本模块改为解**周期约束的三次样条**：对每个关键帧求一个二阶导 `M[i]`，矩阵按
首尾回绕耦合（末帧经长度为 `t0+period-t[n-1]` 的收尾段接回首帧）。每个关键帧
只有一个 `M`，所以相邻三次段在该点值、一阶导、二阶导都相等——包括回绕接缝，
处处 C2。

求值永远先把 `t` 对周期取模，因此 `t + k·period` 与 `t` 完全相等，不会出现末段
三次外推那种随距离增长的频谱放大。

### 增益曲线

对关键帧能分辨的每个模 `k = 0..n/2`，`v[i] = cos(2πk(t[i]-t0)/period)`，用
`pc_gain_curve` 输出三列（RMS 增益）：

| 列 | 窗口 | 含义 |
|---|---|---|
| `base` | 一个完整周期 | 正常应 ≈ 1 |
| `closure` | 收尾段 `[t[n-1], t0+period]` | 由关键帧“合成”的一段，唯一可能 > 1 的地方 |
| `far` | 下一周期 | 因取模而与 `base` 完全相同 |

`periodic_init` 的 `gain_cap` 参数可对 `closure` 的最坏模设上限，超限返回
`PC_ERR_GAIN` 并通过 `out_gain` 报出实测值。`gain_cap <= 0` 关闭检查。

### 自检给出的上界（均匀 8 帧、周期 8）

```
periodic C2 跳变:              c0=0, c1≈8e-8, c2=0
periodic base/far 增益:        ≈1.000（各模均 ≤1）
periodic closure 增益:         ≤1.0（该例）；关键帧集中时可达 ~2.3，由 gain_cap 拦截
整段重建接缝二阶导跳变:        0.751
整段重建远端增益:              2 周期后 ≈5.8e2，5 周期后 ≈1.1e5 且随距离增长
```

即：周期延拓的二阶导跳变≈0、远端增益恒等于基准周期；整段重建的跳变与增益都严格
更差，且增益随外推距离发散。

### 自检中的实测上界（400 组随机配置扫描）

```
C2 跳变上界:               ≤ 4.6e-13（舍入级）
良态配置周期误差上界:      ≤ 3.9e-6
基准周期增益上界:          ≤ 1.66（含紧密相邻帧）
远端增益 / 基准增益:       = 1.000000（逐配置）
```

注意：`pc_eval` 接受 `float t`，而内部用 `double` 归约。若某对关键帧几乎重合
（斜率 ~1e4 量级），`t` 与 `t+P` 在大 `t` 处相差一个 float ULP，代入后误差约为
`斜率 × ULP`，这是输入分辨率而非曲线问题；良态配置不受影响。

### 拒绝条件（`PCStatus`）

| 返回 | 原因 |
|---|---|
| `PC_ERR_PERIOD` | 周期为 0、负数或非有限 |
| `PC_ERR_FEW_KEYS` | 关键帧少于 3 个 |
| `PC_ERR_SPACING` | 时间非严格递增、有重复帧，或关键帧跨度 ≥ 周期 |
| `PC_ERR_CAPACITY` | 超过 `MAX_KEYS` |
| `PC_ERR_GAIN` | 收尾段增益超过 `gain_cap` |

`pc_status_str(status)` 给出可读原因。
