# curve

`make test` 跑自检。

关键帧三次 Hermite 采样，区间外夹取到端点值。两种切线模式：

- **默认（关闭单调模式）**：使用每帧调用方给定的 `tan_in/tan_out`，行为与最初版本逐位一致。
- **单调模式 `curve_set_monotone(c, 1)`**：Fritsch–Carlson 切线。
  - 内部切线初值取相邻差商平均，局部极值处置零，边界帧用单侧差分；
  - 按区间差商限幅（每段 α²+β² ≤ 9，平区间两端切线强制为零），保证每段三次曲线在区间内单调、不过冲；
  - 每帧入/出切线共享同一个斜率，分段曲线为 C1，关键帧处速度无跳变；
  - 单调模式下继续 `curve_add` 会自动重建切线；`curve_set_monotone(c, 0)` 关闭后采样结果与默认模式完全相同。

时间戳必须有限且严格递增：重复、倒序、NaN 一律由 `curve_add` / `curve_build_monotone` 返回 `-1`。

自检覆盖：限幅前朴素平均切线确实过冲、限幅后无过冲、与逐点解析导数（sin/cos）曲线比对极值点数不增加、关键帧速度断点为零、关闭模式后与原公式十六进制浮点逐位相等。
