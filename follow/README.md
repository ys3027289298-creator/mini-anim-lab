# follow

弹簧阻尼相机跟随。质量归一化（m = 1），目标位置 `g`、目标速度 `g'`：

```
e    = x - g                          （带符号滞后）
x''  = -wn²·e - 2·zeta·wn·(x' - g')
```

阻尼器作用在**相对速度**上，因此匀速运动的目标稳态滞后为零（速度前馈）。

`make test` 跑自检。

## 参数关系

| 量 | 关系 |
|---|---|
| 刚度 | `k = wn²` |
| 阻尼系数 | `c = 2·zeta·wn` |
| 临界阻尼 | `zeta = 1`，此时 `c = 2·sqrt(k)`，即 `c² = 4k` |
| 超调量 → 阻尼比 | `zeta = sqrt(L² / (π² + L²))`，`L = ln(Overshoot)` |
| 阻尼比 → 超调量 | `Overshoot = exp(-π·zeta / sqrt(1-zeta²))`（仅 `zeta < 1`） |

- `follow1d_init_critical(f, wn)`：临界阻尼，无超调，最快无振荡收敛。
- `follow1d_init_overshoot(f, wn, os)`：按可配超调分数 `os ∈ [0,1)` 反推
  `zeta`；`os = 0` 等价于临界阻尼。
- `follow1d_init_zeta(f, wn, zeta)`：直接指定阻尼比，支持过阻尼 `zeta > 1`。

`wn`（自然角频率）调响应快慢：2% 稳定时间量级约 `4/(zeta·wn)` 秒。

## 拒绝的配置

`wn <= 0`、`zeta <= 0`、`os >= 1`、NaN/Inf 一律返回 `-1` 且不改动已初始化
的状态。`zeta = 0` 是无阻尼（永不收敛），`zeta < 0` 向系统注入能量，均拒绝。

## 积分与稳定时间上界

- 半隐式欧拉（symplectic Euler），按 `wn·h <= 0.05` 自动子步，30 fps 粗帧率
  与 250 ms 帧卡顿下仍稳定、有界。
- 解析阶跃响应（欠阻尼/临界/过阻尼三分支）作为参考，数值解与其误差 < 0.5%（
  1 ms 步长）。
- 2% 稳定时间上界由解析误差包络给出，自检对解析流严格验证，数值流给与离散
  误差相称的小裕量：
  - 欠阻尼：`t_s <= -ln(0.02·sqrt(1-zeta²)) / (zeta·wn)`
  - 临界：解 `(1+s)e^-s = 0.02`，`s = wn·t`（二分）
  - 过阻尼：`t_s <= -ln(0.02·(b-a)/b) / (a·wn)`，慢极点 `a = zeta-sqrt(zeta²-1)`

## 3D

`Follow3D` 每轴一个独立 `Follow1D`，`follow3d_step` 吃位置与速度向量。
相机平移/旋转（四元数或欧拉分量）均可逐分量套用。
