# fixed

Verlet 距离约束链条的定点化版本，带漂移审计。真值是**定点数位置 + 量化步长 +
按步长推出的误差上界**，与浮点参考结果逐帧比对。

`make test` 跑自检。

## 量化表示

- 步长 `q = 2^-q_bits` 世界单位（`q_bits` 取 1..30）；位置、前一帧位置、静止段长、
  以及**每一条实际施加的修正量**都以 int64 的整数量子存储。
- 几何量（距离、逆质量份额、修正方向）由整数状态以 `long double` 精确计算，
  只在最后把每个可动端点的修正量四舍五入到整数量子——量化只发生在这一处。
- 重力经 32 位小数进位发射：每帧位移是整数量子，但长期平均精确；
  浮点参考消费**同一个**进位发射器，所以重力量化不产生相对漂移。
- 阻尼量化为 32 位定标，两侧使用同一系数。

## 漂移上界与报警

记 `U` 为可动粒子数、`K` 为每帧约束迭代遍数、`S` 为所有约束上的可动端点数
（自由-自由约束计 2，钉死-自由约束计 1）。一帧的舍入预算为

```
r0 = (U + K*S) * q
```

（每帧 2U 次积分舍入 + 2KS 次修正舍入，每次偏差不超过 q/2）。审计分两层：

1. **单帧硬界**：第 0 帧没有历史，漂移必须 ≤ `r0`。这是最锐利的一层。
2. **累计界**：运行到第 N 帧，漂移必须 ≤ `B(N) = N * r0`，即全部舍入预算之和。

两层任一超限都置 `drift_exceeded`，并记录首次越界的帧号、粒子、轴向。自测中
阻尼链条从 `q = 2^-4` 到 `2^-16` 全部留在累计界内；同时用注入故障
（`fault_quant` 让求解器按比 `q` 更粗的步长量化）证明越界时报警确实触发。

**为什么上界不写成"每帧 q/2 的几何级数"**：实测表明链条不是逐帧收缩的——
在欠阻尼/刚性区间，q 量级的差会被动力学放大而不是衰减。累计界 `N*r0` 是
诚实的形式：阻尼链条远低于它；刚性链条会超限，此时报告的是"差异无法由量化
解释"，而不是假装收敛。`fm_report()` 打印 `peak/r0` 与 `peak/(N*r0)` 以区分
两种情况：实现缺陷表现为早期单帧越过 `r0` 且比值停在 1 附近；动力学放大表现为
比值持续增长且远大于 1。自测含一个近无阻尼链条，要求在放大区间如实报出。

## 步长过大 → 不收敛

`q` 过大时，K 遍迭代后仍有距离残差：每遍只能移动整数量子，步长细时残差是 q 的
若干倍，步长粗到单遍越过静止长度后残差随 q 增长。每帧在 K 遍之后以世界单位
测量逐约束残差，超过 `res_tol` 记一帧，定位到残差最大的约束，状态置
`nonconverged`。它与漂移报警相互独立：步长可能对几何来说太粗，而轨迹仍远在界内。
自测的 `residual_scan` 打印 17 个 `q`（`2^-2` 到 `2^-18`）的实测残差，交叉点可见。

`fm_worst_constraint()` 返回首次不收敛帧上残差最大的约束编号，与手工逐约束
核对完全一致（自测中逐帧比对）。

## 状态

`fm_status()` 优先级：`invalid`、`overflow`、`drift_exceeded`、`nonconverged`、
`undetermined`（帧数 < `min_frames` 且尚无任何标志）、`ok`。文字见
`fm_status_reason()`。

- **非法配置**：`q_bits` 越界（含 0/负）、几何/阻尼/重力/`dt`/容差为 NaN 或
  非正、迭代数越界、`min_frames < 1`、或初始范围放不进 int64 坐标上限，
  一律 `invalid`，之后不会被观测"复活"。
- **溢出**：运行中撞到 int64 坐标上限即锁存 `overflow` 并拒绝后续步进，
  而不是回绕成一条看似合理的轨迹。
- **采样不足**：观测帧数不足时返回 `undetermined`，绝不返回 `ok`。

## 浮点参考为什么用 double

比较的目的是把量化误差单独隔离出来。float 自身带着与待测效应同量级的积分漂移
（`../constraint/` 展示的正是这个漂移），用它作参考会把小的量化藏进 float 噪声、
给大的量化叠加噪声。参考链用 double 跑同一算法；在允许的 `q_bits` 范围内
double 的舍入远小于一个量子。两条链从**同一量化状态**起步、消费同一量化阻尼
与同一重力发射，因此差值只来自约束修正的舍入。

## 用法

```c
FixCfg cfg = { .n = 8, .seg = 1.0, .x0 = 0, .y0 = 0,
               .damping = 0.99, .iterations = 8, .q_bits = 12,
               .dt = 0.016, .gx = 0, .gy = -9.8,
               .res_tol = 0.01, .min_frames = 50 };
FixAudit a;
if (!fm_init(&a, &cfg)) { /* invalid q or config */ }
for (int f = 0; f < frames; f++) {
    if (!fm_step(&a)) break;          /* overflow: refuses further steps */
}
FmStatus s = fm_status(&a);           /* ok / undetermined / nonconverged /
                                         drift_exceeded / overflow / invalid */
int con; double resid = 0;
con = fm_worst_constraint(&a, &resid);   /* -1 = converged */
fm_report(&a);                        /* r0, frame-0 ratio, peak/N, localization */
```

## 自检覆盖

配置校验的全部拒绝路径与"拒绝后不复活"；`undetermined` 边界；健康链条
`ok` 且无报警；第 0 帧漂移 ≤ `r0`；细 `q` 收敛、粗 `q` 不收敛且残差定位与手工
一致；提高 `res_tol` 可清除不收敛判定；`q` 从 `2^-4` 到 `2^-16` 的漂移扫描全部
在界内；故障注入的报警触发与定位；溢出锁存与拒绝续步；钉死链的界内与收敛；
高迭代修正量下收敛；残差随 `q` 变粗而增长；近无阻尼链条在放大区间如实报告。
