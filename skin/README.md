# skin

单顶点线性蒙皮的影响集裁剪（最多 8 根骨，原始权重未归一）。

## 算法

1. 校验：影响上限 `max_inf <= 0`、任一权重为负、权重全零（无法归一）一律拒绝。
2. 贪心：按贡献 `w_i * |p_i|` 降序挑选（绑定姿取原点，`p_i` 即骨位移），
   贡献相同比原始权重，再相同按下标。
3. 每选一根，输出被舍弃权重（原始值与占比 `rho_k`）、对保留集重归一后的权重与混合位置，
   以及位移上界 `B_k = 4 R rho_k`（`R` 为正权重骨的最大位移）。
4. 穷举所有同规模子集，取与全量蒙皮位移最小的作为最优集，与贪心结果比对。

## 上界

对任意保留集 S，舍弃集 D：`p = rho_S m_D + (1-rho_S) p_S`，故
`|p_S - p| <= 2 R rho_S`。贪心集 G 与同规模最优集 O 之间：
`|p_G - p_O| <= 4 R rho_G = B_k`。贪心集只增不减，`rho` 单调不增，
选满全部骨时上界为 0。

`make test` 跑自检（含 500 组随机顶点与 100 组负权重拒绝压测）。
