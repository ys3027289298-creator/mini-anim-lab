# grasp

五指耦合抓握求解：每指两骨解析解三角形，五指接触角联立，共享弯曲约束与接触间隙；随后按权重分配接触力。

`make test` 跑自检。自检覆盖：

- 单指解析解（关节同时落在两骨圆上、两个镜像分支、不可达）
- 肘部侧向规则确定且左右镜像对称
- 逐指独立求解 vs 耦合求解的穿透次数比对（独立求解穿透 3 对，耦合求解 0 对）
- 耦合解满足可达、相邻指弯曲共享、接触角偏移上限
- 不可行配置（弯曲上限过紧、偏移上限过紧）返回残差且 `ok=0`，不给近似解
- 力分配总和守恒、与权重成正比；无法实现的比例/外力方向报告残差

## 求解结构

1. **解析单指**：给定指根 `P`、接触点 `T`、骨长 `l1,l2`，由余弦定理求肘关节 `J`。
   肘部取哪一侧由 `outboard_side` 显式决定（远离抓握轴的镜像分支），
   不用叉积——对称起始位姿下叉积恰为 0，会让浮点噪声决定结果，出现左右指互为镜像的穿透。
   因此单指是接触角的纯函数，无需迭代。
   已知限制：肘部侧向按每个位姿重新判定，若某指的“指根→接触点”方向恰好竖直（两侧支对称），
   判定会在两支间跳变；默认参数下解远离该退化情形。
2. **联立决策量**：五个接触角 `phi[5]`。约束写成一维向量 `g[29] >= 0`：
   可达上下界（10）、十对手指间隙（10，骨段脊线距离）、相邻指弯曲差（4）、接触角偏移上限（5）。
3. **增广拉格朗日 + 阻尼最小二乘**：外层更新乘子与罚因子，内层对增广残差做 LM。
   残差超过 `tol` 时 `SolveResult.ok = 0`，并给出最大违约量 `residual`。
   在 1280 组几何参数上做过压测：收敛的 1148 组全部零穿透；未收敛的 132 组经独立
   网格暴力搜索确认均为真正不可行，未出现“可行却报失败”的假阴性。
4. **力分配**：`f_i = lambda * w_i`，`lambda` 由 `G f = w_ext` 的最小二乘拟合得到，
   故比例由构造保证；比例力无法实现所需合力旋量时报告 `resid`，`ok=0`。
   力分配只做到旋量平衡，不单独做摩擦锥投影。

## 参数

`solve_coupled` 使用 `Spec`；默认值见 `spec_default()`（`max_bend=0.30`、`max_shift=0.60`）。
紧到不可行的约束（如 `max_bend=0.05`）会走残差上报路径。
