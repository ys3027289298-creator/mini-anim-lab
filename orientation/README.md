# orientation

角色站立面朝向对齐。`make test` 跑自检。

## 解决的问题

角色站在斜坡上脚底保持水平（不贴合地面），以及转向时打滑。模块逐帧把角色
朝向对齐到地面法线与移动朝向。

## 做法

两级最短弧旋转（`orient_update`），避免每帧用固定世界朝向重建完整旋转矩阵——
那种写法在法线转动时会让朝向投影周期性与法线平行、基底退化并 180° 翻转：

1. **地面贴合**：最短弧 `qbetween(当前上轴, 滤波法线)`，转轴始终在地平面内，
   把局部 `+y` 带到法线。
2. **平面偏航**：绕新上轴做最短弧旋转，把局部前向（局部 `−z`）带到投影到
   地面平面的朝向上；转角由 `atan2(上·(fwd×want), fwd·want)` 给出，天然落在
   `[−π, π]`。

配套机制：

- **角速度上限与阻尼**：每步转角取 `min(阻尼步长, wmax·dt, 残差角)`，阻尼为
  一阶指数 `1−exp(−dt/τ)`；不超调，收敛后帧间转角为零（抖动帧数为 0）。
- **带滞后的法线滤波**：`NormalFilter` 对单位法线做 EMA（时间常数 τ），抑制
  法线噪声；代价是稳态相位滞后，滞后量由自检数值给出。
- **零法线拒绝**：输入法线长度低于阈值时拒绝该样本并保留上一次估计，
  初始化前拒绝则不建立状态。

`orient_target` 保留为解析参考实现（列 = right, up, −forward 的正交矩阵），
自检用它逐列校验旋转矩阵构造。

## 自检输出的关键量（60 Hz）

- 与解析旋转矩阵逐列比对，正交且行列式为 1；上方向误差初始 0.463648 rad、
  最大值不超过初值、终值 0。
- 实测最大角速度 3.0001 rad/s（上限 3.0）；`jitter_frames=0`。
- 滤波稳态滞后（τ=0.25 s、法线 1 rad/s 匀速旋转）：
  - 实测/独立 2D 参考：0.252721 rad
  - 线性 EMA 精确离散模型：0.244479 rad；连续一阶近似 `atan(ωτ)`：0.244979 rad
  - 归一化带来的额外滞后：0.008243 rad
- 端到端上方向偏差 0.252673 rad，数值上等于滤波滞后；前向跟踪误差 0.000061 rad。
- 零法线拒绝/恢复；180° 掉头只绕上轴转 π；60 Hz/30 Hz 帧率一致性漂移为 0。
