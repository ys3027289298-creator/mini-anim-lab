# audit

`constraint/` 求解器的守恒审计器：逐帧统计总线性动量与角动量，与求解器
产生的每一类冲量对账，把偏差定位到具体约束索引。`make test` 跑全部自检。

## 审计原理

求解器（Verlet 积分 + PBD 距离约束）每帧只产生四类动量变化：

| 来源 | 性质 | 审计如何记账 |
|---|---|---|
| 重力冲量 | 外力，已知 | 按求解器自身的 float32 运算序列复算 `m·(g·dt·dt)/dt` |
| 阻尼冲量 | 外力，已知 | 按 float32 复算 `m·(k·v − v)` |
| 锚点冲量 | 外力（pin 粒子 `inv_mass=0`） | 由涉及锚点的约束投影观测 |
| 内部约束冲量 | 内力 | 按约束索引逐事件入账，线性冲量必须成对抵消 |

审计**不修改求解器**，只挂接 `chain.h` 里默认 NULL 的只读观察钩子，在影子
状态中重放观测到的位置增量。每个投影事件的动量变化在位置增量空间计算：

```
dP = m·dx/dt
dL = r⁺×m·v⁺ − r⁻×m·v⁻,   v = (r − r_frame_start)/dt
```

事件在帧内望远镜累加，端点必然等于帧首尾动量，因此每个事件都可以挂到
具体约束索引而账目仍然闭合。影子状态用 float 加法逐位模拟求解器，避免
重放引入额外舍入。

## 关键结论：角动量为什么不守恒

无外力自由旋转链的自检（`noforce_*`）实测：1000 帧内

- 总线性动量漂移仅 2.3e-5（纯 float32 噪声，在舍入上界内）；
- 总角动量从 10.5 衰减到 1.85（**−82%**），且 100% 由内部约束台账解释，
  未解释残差 ~3e-6。

根源是 PBD 投影的**结构性角动量耗散**：每次距离约束投影是非弹性法向
冲量，移除沿约束方向拉伸的速度分量；对旋转链这一分量周期性为径向，
反复投影等价于持续抽走径向动能。线性动量因成对等大反向冲量而守恒，
角动量则因冲量作用点的输运项（位置在帧内变化）而不守恒。这是求解器
算法本身的特性，不是 bug——审计的职责是让它**可见、可归因、无漏报**。

## 对账恒等式与上界

每帧检验：

```
P1 − P0 = J_grav + J_damp + J_pin + J_internal + resP
L1 − L0 = τ_grav + τ_damp + L_pin + L_internal + resL
```

- `res*`（端点残差）必须落在数据驱动的 float32 舍入上界 `boundP/boundL` 内，
  上界 = 积分阶段界 + 投影阶段界 + 端点速度重建的 ULP 下界；
- 望远镜残差（观测累加 vs 端点）实测 ≤ 1.6e-7/帧；
- 无外力情形的累计漂移给出随帧数增长的显式上界。

float32 积分器与连续模型 `m·g·dt` 之间的离散化差（本场景每粒子每帧
~1.2e-8 速度单位，由 `g·dt²` 的 float 量化再除以 dt 产生）单独以
`discGapP` 报告，不计入动量损失。

## 自检用例（28 项）

| 用例 | 验证内容 |
|---|---|
| `hand_pair` | 双自由粒子二进制可精确表示场景，与手工核算逐位一致 |
| `hand_pin` | pin 锚点冲量 −1.5 精确拦截径向粒子 |
| `hand_damp` | 阻尼冲量精确解释动量从 1.5 到 0.75 |
| `noforce_*` | 无外力漂移上界、角动量耗散 100% 归因到约束、内力成对抵消 |
| `noninterference_memcmp` | 挂钩子与不挂钩子的两条链 300 帧逐字节相同 |
| `kick_*` | 阳性对照：未建模的 0.2 冲量必被残差与望远镜同时捕获（零漏报） |

非干扰保证来自钩子只在求解器写完结果后读取其已算出的 float 值，不回写
任何状态；`-O0..-O3` 下自检结果一致。
