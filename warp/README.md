# warp

两条采样轨迹（位置 / 旋转 / 缩放三条频率不一致的曲线）之间的时间扭曲对齐。
`make test` 跑自检（27 项）。

## 做什么

- **动态规划求最小代价映射**：在帧对网格上做 DP，从 `(0,0)` 走到
  `(nA−1,nB−1)`。每次转移的代价为
  `w·(w_pos·位置差² + w_vel·速度差²) + w_bend·w·|局部斜率 − 1| +
  w_smooth·|本步斜率 − 上一步斜率|`，其中步长 `w=(Δi+Δj)/2`。
  各通道按自身值域归一化，角度通道（`wrap_chan`）按最短角弧处理、周期 2π。
- **长度归一化为什么必要**：转移代价乘以步长 `w`，长跳步要为它跨过的每一
  帧付费，DP 无法靠少走格子来降低总代价（朴素逐格累加会让"跳得越粗越省"，
  退化成只有少数节点的粗糙映射）。
- **斜率平滑项为什么必要**：周期信号（纯正弦、循环旋转）在不同时刻取值相同，
  点值代价的最小值很平、存在歧义；`w_smooth` 作为平滑先验在这些近似打平的
  候选里选斜率连续的路径，并抑制逐格抖动。它不压真实的缓慢弯曲，只惩罚
  相邻步的斜率突变。
- **单调 + 斜率上下界**：每一步两个索引都严格递增（物理时间单调）；每步的
  物理时间斜率 `ΔtB/ΔtA` 必须落在 `[slope_min, slope_max]` 内。默认界为
  有限区间，因此 `Δi=0 / Δj=0` 的退化步会被直接拒绝；任何路径都满足不了
  界时返回 `WARP_ERR_INFEASIBLE`，不返回非法结果。
- **按映射重采样**：`warp_resample` 把 B 沿分段线性映射重采到 A 的帧网格，
  角度通道沿最短角弧插值。
- **与手工对齐比对**：`warp_manual_compare` 吃手工锚点对，给同步误差上界
  （锚点集合上的最大绝对时间误差，另附均值 / RMS / 最大锚点间距）。注意这是
  **锚点处的离散上界**，不是锚点之间的连续数学保证——两条映射都是分段线性，
  区间内偏差由端点与帧间距共同决定，`max_gap` 越大插值越粗。
- **预算保护**：网格单元数超过 `WARP_BUDGET`（4096）时**不硬跑**，返回
  `WARP_ERR_BUDGET` 并给 `DecimPlan`：推荐的 A/B 降采样步长、降采样后的
  格点规模（保证 ≤ 预算），以及备选的 Sakoe-Chiba 带状窗口宽度与对应单元数。
  调用方按 `warp_decimate`（保留每第 k 帧且始终保留末帧）降采样后重试即可。

## 代价与口径

- 时间在内部归一化到 `[0,1]`，斜率界 `slope_min/slope_max` 按物理时间
  口径解释（1.0 = 等速）。
- 弯曲惩罚衡量局部步斜率相对恒等映射（1:1）的偏离；路径另外上报
  `max_slope` 与 `max_slope_change` 供审查映射的抖动程度，`mean_cell_cost`
  按累计步长 `total_weight` 归一化，与路径粗细无关。
- 同步误差的下限受离散网格分辨率约束：映射是分段线性的，时间精度不可能
  优于参与轨迹自身的帧间距，自检中的误差上界即按"若干个 B 帧间距"设定。
- DP 工作区是文件级静态存储（`WARP_MAX_N=256` 帧 / `WARP_MAX_CHAN=6`
  通道 / 单步最多跳 `WARP_MAX_STEP=8` 帧），模块非可重入。

## 自检覆盖

真值弯曲 `tA = u + 0.08·sin(2πu)` 构造 3 通道动画式信号（缓入缓出位置 +
循环旋转 + 单调缩放，多形态打破周期歧义），验证：端点锚定、严格单调、
斜率有界、时间域映射精度、重采样后三通道恢复原信号（旋转按最短角弧计误差）；
手工锚点误差上界与落在求解节点上的锚点零误差；超预算拒绝并给出可行降采样
方案（降采样后重试成功、末帧保留）；过紧斜率窗返回不可行；非法输入拒绝。
