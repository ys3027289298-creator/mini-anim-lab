# retarget

换名骨骼之间的重定向。`make test` 跑自检。

## 流水线

1. **层级路径描述符**：每根骨记录 root→自身的完整路径与深度，路径完全相同直接命中（`path`）。
2. **骨长链比例**：沿层级链取每段长度占链总长的比例，候选间用比例剖面的最大偏差比较，而不是比绝对骨长——整体等比缩放的新骨骼偏差为零。
3. **名称相似性**：下划线分词 + 小写化后的 token Jaccard 相似度，作为同深度、同拓扑候选的排序信号。
4. **冲突处理**：候选同分或分差小于 `SCORE_MARGIN` 时不硬选，`dst` 留空并输出候选列表（`conflict`，含每候选分数）。
5. **比例超阈**：所有结构候选的链比例偏差都超过 `RATIO_THRESH`（0.10）时拒绝映射并出 `ratio_block` 报告，绝不硬套；0.05~0.10 之间照映射但出 `warn`。
6. **骨长恢复**：`rt_recover()` 把目标骨骼工作长度复位到静息长度并重算 FK，返回关节间距相对静息长度的最大残差，上界 `RESID_BOUND = 1e-5`。
7. **网格边长检查**：
   - 自动映射与手工映射的蒙皮结果逐边比对，边长畸变上界 `DISTORT_BOUND = 0`；
   - 同骨两端边为刚性边，最大边长比上界 `1 + 1e-4`；
   - 跨关节边在温和姿态下整体最大边长比上界 `1.05`；
   - 错误映射（大小腿交换）同一检查必须能检出。

## 自检场景

- `clean_*`：改名但等比缩放的新骨骼，四骨全部唯一映射，比例偏差为零且无报告；
- `conflict_*`：两条等长等比的腿，髋骨命中、腿骨全部给双候选并出冲突报告；
- `ratio_*`：比例严重失真的骨骼被拒绝映射并出报告；
- `recover_*`：人为拉伸/压缩工作长度制造「整条腿被拉歪」，恢复后残差在界内；
- `auto_vs_manual_*` / `rigid_edge_*` / `overall_edge_*`：与手工映射零畸变；
- `bad_mapping_detected`：错误映射在边长检查中暴露。
