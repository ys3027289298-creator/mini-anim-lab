# pose

关键姿态插值：每帧先从两端姿态的关节朝向插值出参考向量，按轨迹平面定向，再解双骨 IK，避免中间帧落入另一侧可行解（膝盖翻面）。

- 定向规则不写死：参考向量 = 两端姿态膝盖弯曲方向（膝盖相对髋→踝轴线的偏移方向）的归一化插值。
- 内置站立、半蹲、全蹲、起立四个关键姿态，相邻两段之间各插 20 帧，共 60 帧。
- 逐帧输出膝盖朝向与地面的夹角；相邻帧角度跳变超过 90° 记为翻面并标 `FLIP`。
- 翻面帧超过 2 帧时，逐翻面帧并列输出所选参考向量 `ref` 与实际膝盖朝向 `actual`，用于排查参考向量选择。
