# hysteresis

绳子（一维本构）材质滞回模块。`make test` 跑自检。

## 模型

- **加载曲线（骨架）**：分段线性 `HyPoint{eps, sig}`，应变严格递增、过
  原点；每段斜率即该拉伸率区间的刚度，按拉伸率给不同刚度。超出末个
  关键点按末段斜率外推。
- **卸载曲线（缩放 Masing 仿射映射）**：在转向点 `et` 处把骨架仿射重映射
  到区间 `[er, et]`：

  ```
  sig_un(eps) = F( (eps - er) * et / (et - er) )
  ```

  它在转向点 `(et, F(et))` 与骨架应力、斜率连续，在残余应变 `er` 处应力
  归零，因此松手后绳子停在 `er` 而不是回到原长。再加载沿同一条分支回到
  转向点后无缝并回骨架，分支由相位状态机记住。
- **滞回环面积可配（闭式）**：`hy_init(..., dissip)` 的 `d ∈ [0,1)` 是
  耗散能占加载做功的比例。仿射映射下环面积恒等式精确成立：

  ```
  er = d * et
  W_unload = (1 - d) * W_load
  loop_area = W_load - W_unload = d * W(et)
  ```

  无需迭代或二分。`d=0` 即纯弹性：`er=0`、环面积为零、完整回弹。
- **曲线记录**：`Recorder` 分别存加载、卸载两条采样曲线（转向点作为两条
  曲线的公共端点），`curve_area` 梯形积分得到实测环面积，随采样加密收敛
  到闭式值。
- **手工测试比对**：`hy_compare` 接收带相位标记（加载/卸载）的实测点，
  输出应力最大绝对/相对偏差，并给出回弹终点应变误差上界

  ```
  resid_bound = 最大卸载应力偏差 / 卸载分支最小斜率
  ```

  卸载分支是骨架的单调重参数化，其最小斜率 = 骨架最小斜率 × 映射比，
  解析可得；一维应力偏差沿最软斜率传播到零应力交点，是保守上界。
  `zero_crossing` 线性插值实测零应力点，自检核验该上界确实覆盖实测偏差。
- **Verlet 驱动**：`Rope` 用滞回本构替换约束链的距离投影，演示拉伸到
  1.5 倍后松手：滞回材质停在残余应变（约 0.148，模型残余 0.15），弹性
  材质回到原长（约 −0.0006）。

## 报错

| 码 | 触发条件 |
|---|---|
| `HY_ERR_TOO_FEW` | 骨架少于 2 个关键点或超容量 |
| `HY_ERR_ORDER` | 应变不严格递增 |
| `HY_ERR_ORIGIN` | 首点不是 `(0,0)` |
| `HY_ERR_STIFFNESS` | 任一段斜率非正（零/负刚度）或非有限 |
| `HY_ERR_DISSIPATION` | `d` 越界（`<0`、`>=1`、非有限） |
| `HY_ERR_STRAIN` | 查询应变为负或 NaN |
| `HY_ERR_CAPACITY` | 分支点/记录点超容量 |
| `HY_ERR_FINITE` | 输入含非有限值 |
