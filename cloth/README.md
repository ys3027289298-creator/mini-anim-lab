# cloth

`make test` 跑自检（`-pthread`，需要多核机器）。

空间分块并行求解。网格按列切成连续的块，切缝上的列由两侧块共享：

- 每个块只负责自己列范围内的顶点（积分、投影、回写都只碰这些顶点）。
- 一个块投影所有触及自己顶点的距离约束，结果写进自己的修正缓冲区。
  接缝约束会被两侧各算一次，用的是同一份迭代起始位置，因此两侧结果逐位相同——
  这就是"边界约束由相邻块共享仲裁"。
- 每个顶点按全局约束索引顺序累加入射约束的修正量，所以切块只改变"谁算"，
  不改变浮点加法顺序。任意块数下分块解与整块解**逐位一致**，接缝错位恒为 0。
- `share_seams = 0` 时不投影接缝约束，各块孤立求解；`cloth_mismatch()`
  会报出与整块解的最大顶点偏移、超阈值顶点数及其中位于接缝列的数量，
  撕裂因此可被检出。
- 块数为 0 或负数时 `cloth_build_blocks()` 返回 -1，未建块时
  `cloth_solve_blocks()` 也返回 -1。

`make test` 打印的耗时为各块数下的最好成绩，并给出倍速：

```
timing blocks=1 ms=...
timing blocks=2 ms=...
timing blocks=4 ms=...
timing blocks=8 ms=...
speedup_2=... speedup_4=... speedup_8=...
```
