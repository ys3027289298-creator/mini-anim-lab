# timeline

统一时间轴：固定步主时钟归并 fixed / audio / network 三路事件。`make test` 跑自检。

## 设计

- **固定步无累积误差**：主时钟只存整数 tick，`time = tick * dt`；外部流逝时间进累加器，按整步消费，浮点只剩余量。
- **网络时钟拟合**：NTP 四时间戳
  - `rtt = (t4-t1) - (t3-t2)`
  - `θ = ((t2-t1) + (t3-t4)) / 2`
  - 对样本按 `w = 1/rtt` 加权最小二乘拟合 `θ(t) = a + b·t`（a 偏移，b 频率漂移），高 RTT 的离群点权重自然压低；远端事件经 `local = remote - θ(t)` 换算到本地域。
- **同刻稳定排序**：事件量化到 tick 网格，键 `(tick, priority, seq)`；`seq` 为全局到达序号，插入排序保证同优先级按到达顺序。
- **漂移补偿**：外部参考时钟（如音频硬件钟）相对网格差满一个 dt 时，只做一步限幅修正，偏差始终有界，补偿次数可查。
- **倒流报错**：各路本地域时间戳必须单调；负 elapsed、非法 RTT 顺序、远端 t3 倒退均返回 `TL_ERR_BACKWARDS` / `TL_ERR_PARAM`。

## 自检覆盖

1. WLS 拟合偏移/漂移、最小 RTT、远端→本地换算、采样环容量
2. 各类时钟倒流与非法参数报错
3. 十万步累加无浮点累积误差、分数步余量
4. 参考钟偏快/偏慢时补偿有界
5. 三路归并与朴素参考序列的顺序、id、各路次数完全一致
6. 同 tick 优先级排序与同优先级到达稳定性
7. 不同喂入节奏（缩放/不缩放）输出顺序与次数一致
8. 事件容量上限
