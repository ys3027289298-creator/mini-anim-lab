# order

蒙皮与约束解算的顺序对比与选序。

- 两种顺序：A = 先蒙皮再解约束（世界空间求解），B = 先解约束再蒙皮（绑定空间求解）。蒙皮是逐顶点不同的线性映射，约束投影是非线性的，两者不可交换，画面因此不同。
- 条件数：蒙皮映射 κ = 顶点缩放的最大/最小比（权重未归一化或旋转相位相消时恶化）；约束雅可比 κ 由 G = J Jᵀ 的特征值给出（链条拉直时按 O(n²) 恶化，零长段直接奇异）。
- 误差增长：逐次扫描的残差比，>1 即增长。
- 选序依据：世界空间锚定 → A；权重未归一化 → B；两者条件数都温和时等价，默认 A；无任何场景事实 → 报 `ORDER_ERR_NO_BASIS`；κ 越过失稳阈值（1e6）→ 报 `ORDER_ERR_UNSTABLE` 并打印阈值。
- 差异上界：|A − B| ≤ (dispA + κc·residA) + smax·(dispB + κc·residB)，自检里与两帧手算结果比对。

`make test` 跑自检。
