# sync

动画事件时钟与音效时钟的重采样比估计，`make test` 跑自检。

## 模型

配对时间戳 `(x_i, y_i)`（x = 动画事件时钟，y = 音效时钟），拟合

```
y = a + b*x + e
```

斜率 `b` 即实际重采样比；两时钟漂移按 `(b - 1) * 经过时间` 累积。

## 流程

1. **稳健初估**：Theil–Sen 配对斜率中位数，约 29% 污染崩溃点，异常点带不偏初值。
2. **异常剔除**：用残差绝对值下半区中位数做稳健尺度（异常点占多数时尺度也不被污染），
   `3.5σ` 标记后 OLS 重拟合，最多迭代 3 轮。
3. **拒绝而非硬拟合**：异常点比例 > 25%、样本 < 8、x 无跨度、拟合退化，全部返回
   `rejected=1` 加原因码（`outlier_fraction_too_high` / `residuals_nonstationary` / …）。
4. **置信区间**：OLS 斜率标准误 × Student-t 95% 双侧临界值（df ≤ 30 查表，否则正态）。
5. **确定性误差上界**：若给有界噪声 `|e_i| ≤ E`，返回最坏斜率误差
   `E · Σ|x_i − x̄| / Sxx`，自检中逐条验证真实误差不越界。
6. **残差不发散**：三项平稳性检查，任一超过 4σ 即判 `residuals_nonstationary`——
   - 半窗均值漂移（t 检验）
   - **Chow 断点检验**（F 检验，经 Wilson–Hilferty 变换映射到 z）：比率中途突变产生 V 形残差，
     两半窗斜率反号，单纯比斜率差会抵消，F 检验保留了完整信号；渐变漂移同样会触发
   - 累积残差随机游走幅度

## 自检覆盖

- 精确直线恢复、点太少 / x 无跨度拒绝
- 200 组高斯噪声蒙特卡洛：全部接受、95% 区间覆盖率 ≥ 90%、残差全部平稳
- 500 组干净数据平稳性假阳性 ≤ 1%
- 有界均匀噪声 100 组：确定性上界逐条成立（输出最坏实际误差与最坏上界，ppm）
- 10% 粗大异常点：正确剔除且真值仍在区间内
- 60% 污染：拒绝估计（不硬拟合）
- 中途突变比率 / 全程渐变比率：残差非平稳拒绝
