# ik

双骨解析 IK：余弦定理求张角、关节行程夹取、极向量定弯曲侧；另配独立的
逐帧数值参照解（黄金分割，double 精度）做交叉校验。`make test` 跑自检。

## 求解口径

- 张角 `gamma`：第一骨与 root→target 连线的夹角，范围 `[0, PI]`，由余弦定理
  `cos(gamma) = (l1² + dist² − l2²) / (2·l1·dist)` 求出。
- 限制：启用后把 `gamma` 夹取到关节行程 `[min_bend, max_bend]`；目标不可达时
  返回行程内最接近的姿态，不再整肢翻折。不启用时保持原有可达性契约
  （超距/过近返回 `IK_ERR_UNREACHABLE`），姿态与旧求解器逐位一致。
- 极向量：`cross(dir, pole)` 的符号决定弯曲侧；夹取只改张角，不改侧别。
- 错误：骨长 ≤ 0 → `IK_ERR_ZERO_BONE`；目标与 root 重合 →
  `IK_ERR_TARGET_AT_ROOT`；行程非法（越界或下界大于上界）→ `IK_ERR_BAD_LIMIT`。

## 自检验收（2400 个随机帧 × 4 组行程 × 限制开关）

- 解析解与数值参照解的关节位置最大误差上界 `1e-4`（实测约 `1e-6`）；
- 行程越界次数必须为 0（张角几何回测 + 弯曲侧回测）；
- 限制关闭时 200 帧随机姿态与旧实现完全一致（容差 `1e-5`）；
- 近距目标演示：无限制时自由张角 2.52 rad，限制在 1.2 rad 时姿态停在行程
  边界，不翻折。
