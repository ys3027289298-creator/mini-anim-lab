# frame

沿折线的平行传输标架（parallel transport frame）与闭合修正，`make test` 跑自检。

## 算法

1. **切向**：每条边归一化为单位切向；边长为零（零向量切向）直接拒绝（返回 `-2`）。
2. **平行传输**：每个顶点处标架按相邻切向的夹角（`wrap` 到 `(-π, π]`）旋转，
   朝向角为解包裹的累加值，避免逐点 `atan2` 在反向处出现的 π 翻转。
3. **闭合 holonomy**：闭合路径多一条回到起点的边，跨接缝的转角存入 `delta[0]`；
   全圈累计转角即 holonomy，`holonomy / 2π` 为传输绕数。
4. **解析比对**：按转向数定理独立累加切向转角得到解析绕数（必须为整数），
   另用射线绕数对内部点做第二次独立核对；两者不一致返回 `-4`。
5. **均匀摊回**：残差 `holonomy - round(winding)·2π` 均分到 n 个传输步并重建标架；
   其中 n−1 个内部步取 `residual/n`，接缝步吸收精确余量（含浮点舍入），
   保证全圈转角构造性地等于 `2π·w`，闭合朝向误差为零（检查容差 `1e-5`，否则 `-6`），
   修正后绕数为整数、残差清零。

## 拒绝条件

| 返回值 | 含义 |
|---|---|
| `-2` | 零长度边，切向为零向量 |
| `-4` | 传输绕数与解析绕数不符（`WIND_MATCH_TOL = 0.25` 圈） |
| `-5` | 摊回后跳变：单步摊回量超过 π/2，或修正步长达到 π（半转翻转） |
| `-6` | 摊回后闭合朝向误差仍不为零 |

开放路径只做第 1–2 步，不做闭合修正。
