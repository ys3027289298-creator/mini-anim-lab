# redik

冗余 IK：躯干与双手联合求解（阻尼伪逆），次要目标经零空间投影嵌入，按优先级降级。

- 主任务：双手末端位置，7 自由度（躯干平移+旋转、双肩双肘）联合求解。
- 次任务：关节回中，只作用在主任务零空间内；投影对主任务线性残差的扰动有上界 `(lambda/2)*alpha*|g|`。
- 报告：末端误差及后验上界（线性残差 + Taylor 余项）、收缩因子 kappa、关节漂移及上界（三角不等式 / 伪逆范数 `|e|/(2*lambda)`）。
- 降级：目标维数超过自由度返回 `REDIK_INFEASIBLE_DOF`；目标不可达返回 `REDIK_DEGRADED` 并给出最小二乘最优位姿（关节限位内）。
- 自检中与纯伪逆解对比：主任务误差相当，次任务代价更低。

`make test` 跑自检。
